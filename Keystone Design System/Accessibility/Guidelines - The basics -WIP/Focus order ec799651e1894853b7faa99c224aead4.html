Focus order

Focus order, also known as keyboard focus order or tab order, refers to the sequence in which elements on a web page receive keyboard focus when a user navigates through the page using the "Tab" key. Screen reader, keyboard, and other assistive-technology users may navigate and interact with our apps without the use of a traditional mouse or touch screen.

How to test the focus order

Pressing the tab key continuously on a browser will focus on all interactive elements in order.

If a screen reader is turn on, then continuously pressing tab will focus on all elements.

Focus order starts from main content when clicking on a link - when you are on the page and you move to another page then focus will start not from the top but from the main content.
Here are some best practices for ensuring a proper focus order:

Natural Flow:
Organise the focus order to follow the natural reading and navigation flow of the content. Users should be able to tab through elements as they would read or interact with them visually.

Logical Order:
Elements should be presented in a logical order. Typically, this means top-to-bottom and left-to-right for most languages and cultures.

Languages:
Left to right - the order goes from top to bottom and left to right (e.g. English).
Right to left - the order goes from top to bottom and right to left (e.g. Arabic).

Skip Links:
Include skip links at the beginning of the page to allow keyboard users to jump directly to the main content, navigation, or other essential sections of the page. This helps them bypass repetitive elements, such as the header and sidebar, and quickly access the relevant content.

Form Elements:
Ensure form fields follow a logical order. For example, in a registration form, the focus should move from the username to the email, then the password fields, and so on.

Visible Focus Indicator:
Provide a clear and visible focus indicator for elements in focus. This indicator should be easy to distinguish from the default outline that browsers provide. It helps users understand which element currently has focus, aiding those with visual impairments or cognitive challenges.

Avoid Trapping Focus:
Make sure users can navigate to all interactive elements on the page using the "Tab" key and can also navigate away from each element. Avoid trapping the keyboard focus within certain areas, as it can be frustrating and confusing for users.

Test with Keyboard Navigation:
Regularly test the website's focus order and overall keyboard accessibility using only the keyboard. This helps identify any issues and ensures a seamless experience for keyboard-only users.
