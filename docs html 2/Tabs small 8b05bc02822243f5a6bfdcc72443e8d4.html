Tabs small

Figma linkStorybook link

Tabs small let users switch between different views of the same content. We currently only use it on the Complex table (Genius) component to switch between viewing data as a list or a table, but we could use it in other scenarios in the future.

Use when

Displaying different views of the exact same data.

Don't use when

Displaying different but related content, use Tabs instead.

Elements

  1. Unselected tab – Other available tab or tabs.
  1. Selected tab – Active tab indicated by light background.

Visual

Alignment

Centre align labels within each tab.

Never centre align tabs small within its container. Always either right or left.

Colour

Tabs use specific base-2 colour palettes. See more details on Colours.

ElementColour token

Selected tab labellayout–content–secondary

Tab label

  • Tab labels should clearly explain the content within.
  • Should be distinguishable from all other tabs.
  • Keep to 1 or 2 words if possible that summarise key descriptive words, usually nouns.
