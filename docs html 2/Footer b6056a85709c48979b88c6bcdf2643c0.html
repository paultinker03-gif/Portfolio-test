Footer

Figma linkStorybook link

Footers are content blocks that anchor to the bottom of the page. Footers contain legal content like terms and conditions, language select and ‘Powered by’.

Use when

Displaying legal content, language select and ‘Powered by’ that is the same throughout the platform.

Don't use when

Displaying information critical to the journey, place it on the main page content instead.

Variants

VariantPurpose
DefaultThe standard footer used in the majority of cases.
Language select (optional)Allows the user to change language. This features is only available on some platforms. See Multilingual.
Powered by (optional)Used to boost awareness of partnerships between businesses. The logo is also an external link that takes users to the relevant provider's website.

Elements

  1. Container – Defines the content block.
  1. Description – Usually terms and conditions. Should include relevant links for legal purposes.
  1. Links – Usually links to legal information.
  1. Language select (optional) - Allows the user to select a different language.
  1. Powered by (optional) - Boosts awareness of partnerships between businesses.

Visual

Placement

Place at the bottom of every page.

Groups

Use only one footer per page.

Colour

The footer can use any of the four base palettes, see Colours for more information.

When applying ‘Built with Keystone by Smart’, on SPMT products use the duo logo, for all other partners use the black logo.

Content

Description

  • Content within the footer is the same in every instance within a platform.
  • Collaborate with local teams to form legal content.

Links

  • Be as specific as possible and avoid generic links like "Click here".
  • No full stop is necessary.
  • See our guidelines for writing links on our grammar and formatting guidelines.
