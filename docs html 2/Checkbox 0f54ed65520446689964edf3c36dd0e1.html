Checkbox

Figma linkStorybook link

A checkbox is an input control that should:

  • collect information
  • let a user select none, one or multiple options from a list

Checkboxes use our Form control - basic structure as a base.

Or

Without label and hint text

Use

  • Select none, one or multiple options from a list of related items.

Don't use

  • Select from a list of mutually exclusive options. Use the Radio instead.
  • Select from a long list of options. consider using Select instead.

Visual

Elements

  1. Group label – Identifies the group's purpose
  1. Hint text (optional) – Describes the checkbox group
  1. Selected checkbox – Indicates when a box has been selected
  1. Unselected checkbox – Indicates when a box has not been selected. The default state.
  1. Checkbox label – Defines the checkbox option
  1. Checkbox hint text (optional) – Describes the checkbox in more depth

Alignment

Align the group label to the right of the checkbox.

Vertically stack the checkboxes to make them easier to scan.

Groups

If the list of items is too long, consider:

  • separating one list into multiple lists with headings
  • using Select instead

Behaviour

States

UnselectedThe default view of a checkbox is having no options selected.
SelectedWhen users select a new checkbox, all previous selections will remain selected.

Nesting

Other form elements can be nested underneath a checkbox in a parent and child relationship. For example, selecting a checkbox option can reveal a radio group option.

Content

Group label

Use to describe the broad category of checkboxes or what actions users can take.

Hint text (optional)

See our guidelines on hint text in Form control - basic structure.

Checkbox label

  • Always use clear and concise labels when possible.
  • End with a full stop if the label includes more than one sentence.
  • Labels appear to the right of checkbox inputs.
  • Avoid using links in the label.
  • List options in a logical order. For example, most likely to least likely to be selected.
  • Avoid ordering alphabetically because this doesn't localise to other languages.
  • Make sure labels don't overlap. For example, low, low/medium, high.
