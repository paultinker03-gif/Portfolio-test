Badge

Figma linkStorybook link

Badges are small visual indicators used to communicate granular detail about other elements. This could be a number value, such as percentage totals, or dynamic status information. Badges cannot be selected or interacted with.

We use badges most often in Sticky footer, Simple table, Cards - Information and Complex table (Genius).

Use when

  • Displaying dynamic numeric values.
  • Displaying the dynamic statuses of other elements.
VariantPurpose
SuccessLets the user know their action was successful.
NegativeIndicates when an action was unsuccessful and the user needs to resolve it to continue.
WarningWhen the action was partially unsuccessful but it doesn't block the user from continuing.
InformationWhen displaying neutral information with no consequence and when an action is pending. There are two variants of information badge, depending on which background they're on: name1 and name2.

Elements

  1. Badge – badge colour helps indicate the variant.
  1. Label – short description of the status.

Visual

Alignment

Align to the right or left of the container.

Each context has a typical direction of alignment. For example, badges in the genius are usually aligned to the right.

Keep alignment consistent within the other components they're placed in.

Groups

Only one badge per element. We don't currently support multiple badges.

No limits on how many badges per page.

Sizes

There are two sizes for badges. Use xs for badges with text and 2xs for numerals.

Typography

All badge labels use regular-sm styling.

Colour

Badges use specific colour palettes by variant, all on the base–2 palette except for information–name1.

VariantToken
Successpositive-secondary–core
Errornegative-secondary–core
Warningwarning-secondary–core
Information–name1info-secondary–core
Information–name2layout–core

Behaviour

Badges are static components that users cannot interact with.

Content

  • If possible, keep to one word. Two words if needed.
  • Write in sentence case.
  • Text must be clear enough to distinguish immediately without only relying on colour.

Standard badge terms

Success: "Success"

Negative: "Mandatory" or "Fail"

Warning: "Optional", "Error" or "Errors detected"

Information: "Pending"
