Spacing tokens

We use a responsive spacing scale which adapts based on screen size.

Sizes

Spacing sizes are consistent across mobile, tablet and desktop from size none to md. However this changes from size lg and higher. For example, if you apply the 3xl spacing size it will be 32px on mobile, 36px on tablets and desktops.

Sizes in rem to pixels

Using rem units gives us flexibility in our designs, and the ability to scale elements up and down, instead of being stuck with fixed sizes. We can use this flexibility to make our designs easier to adjust during development, more responsive, and to allow browser users to control the overall scale of sites for maximum readability.

When using rem units, the pixel size they translate to depends on the font size of the root element of the page, i.e. the html element. That root font size is multiplied by whatever number you’re using with your rem unit.

For example, with a root element font size of 16px, 10rem would equate to 160px, i.e. 10 x 16 = 160.
