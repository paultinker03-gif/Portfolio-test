Colours

Each partner has a colour theme which provides fixed colours for backgrounds and overlapping components. We split our themes into four base palettes – base–1, base–2, base–3 and base–4. For example:

SPMT

Blockbase/palette
Primary navigationbase-3
Body area, main contentbase-2
Footerbase-1
Bannerbase-4

See Partner themes for more information about each partner.

We define each colour token within categories depending on its purpose. This includes layout, highlight, highlight–outline, positive–primary, positive–secondary, negative–primary, negative–secondary, negative–outline, warning–primary, warning–secondary, info–primary and info–secondary.

Colour ratio = minimum required to meet level AA accessibility. See more in Accessibility overview.
