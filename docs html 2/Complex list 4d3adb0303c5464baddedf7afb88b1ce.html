Complex list

Figma linkStorybook link

Complex list presents small groups of related information. Such as a label and description, but also a badge add/or icon.

Use when

  • when you need to display more details than a List will allow.

Don’t use when

  • you want to display a lot of information - use the Complex table (Genius).
  • information that can be filtered - use the Complex table (Genius)

Elements

  1. Label - Short heading clearly describing list item.
  1. Description (optional) - Additional information.
  1. Elements (optional) - Displayed on the right. Allowed elements: Functional Icons,Badge, Switch.

Visual

  • always left align the label and description
  • always right align the badge and/or icon

Behaviour

  • There are two general states:
    • Clickable - The whole area is clickable.
    • Non-clickable
  • Include a divider between every item on desktop only. This helps users read longer line lengths which aren't needed on smaller screens.
  • When used within the inbox section of the member app, use bold for both the label and description to mark an item as unread.
