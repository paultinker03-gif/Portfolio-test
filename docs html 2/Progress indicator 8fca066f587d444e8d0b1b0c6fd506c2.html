Progress indicator

Figma linkStorybook link

A progress indicator communicates a user's progress while completing a series of specific steps.

The progress indicator displays how many steps there are in a user journey, versus how many are left to complete. By dividing a task into smaller sub-tasks, we help users keep on track to complete it.

Use when

  • Displaying relative progress of a task.
  • Guiding users through a multi-step wizard.

Elements

  1. Label – Describes which step the user is currently on compared to the total number of steps.
  1. Bar – The visual indicator shows relatively how much is left of the task.

Visual

Placement

Place the progress indicator at the top of the page, above the Page heading.

Typography

The label uses sm-regular styling.

Colour

Colours are on the base–2 palette.

ElementColour token
Stepslayout-content-secondary
Bar completedpositive–primary–core
Bar not completedlayout–contrast

Behaviour

Users must navigate through another step in the wizard for the label and bar to show further progress.

When the label text exceeds the space towards the bar, the content flows to multiple lines within that set width (14 characters in English).

Content

  • The label should describe the users' progress relative to completion.
  • Keep short and concise, to one line if possible.
  • The text wraps into multiple lines if too long.

Standard labels

In English, describe the label as Step {current number} of {total number}. For example, 'Step 2 of 5'.
