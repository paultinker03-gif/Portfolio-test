Tag

Figma linkStorybook link

The tag component is used when a filter is applied to feedback to the user what filters they currently have active. This filter can be deactivated by clicking the 'x'.

Visual

Elements

  1. Container – Defines each filter
  1. Label – Signposts which filter has been added
  1. 'x' icon – Used to deactivate the filter

Alignment

The tag container will hug the content.

Groups

The tags are always inline, but will stack if their content is too long.

Behaviour

States

Button statesPurpose
DefaultUser hasn't interacted with the tag yet.
FocusUser has selected the button using their keyboard.
ActiveUser is currently selecting the button.

Content

  • If possible, keep to one word. Two words if needed.
  • Write in sentence case.
