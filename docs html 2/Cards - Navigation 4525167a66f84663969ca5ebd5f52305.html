Cards - Navigation

Figma linkStorybook link

Cards navigation are clickable areas that allow users to navigate through the platform. We only use them on dashboard and navigation templates, and they are less flexible than Cards - Information. There are three variants depending on their purpose and visual styling – data, default, and table.

Use when

  • Presenting navigation options on dashboard and navigation templates.
  • Allowing users to select the card to go to the next option.

Don't use when

  • Grouping non-navigational static information, use Cards - Information instead.
  • A strong nudge is needed to action the user to perform a specific task, use Cards - Highlight (Nudge) instead.

Alignment

Left-align all content to the right of the hi-fi icon.

Groups

  • Multiple cards can be grouped together.
  • On mobile, stack cards vertically on one column only.
  • On desktop and tablet, you can stack half-width cards along two columns if needed.

Spacing

Padding and spacing between cards are fixed according to the viewport.

PaddingSpacing between cards
Mobile16px16px
Tablet and desktop20px20px

Text

Title

  • Keep titles clear and concise.
  • Should highlight the most important point of the card content.
  • Should match the page they link to.
  • Use the title to distinguish it from all other cards when there are multiple grouped.
  • Limited to one line (as seen on a mobile screen), three words only.

Description

  • Use to provide additional context to the title if needed.
  • Like titles, use to distinguish from other grouped cards.
  • Limited to two lines (as seen on a mobile screen), 80 characters including spaces
