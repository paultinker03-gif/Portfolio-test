Banner

Figma linkStorybook link

Banners communicate a short, important message relevant to the platform at the top of a page. This could be to promote something important to the business.

The banner should be the first element on every page. They're persistent unless users dismiss it or navigate away from the page. Show only one banner at a time.

Use when

Communicating a prominent message.

Elements

  1. Container – Defines the banner message.
  1. Title (optional) – Short heading clearly describing the purpose of the banner.
  1. Close icon – Signifies that the banner is dismissible.
  1. Description – Can include a link to another page or external source.

Visual

Alignment

Centre align the title and description.

Placement

Anchor the banner at the top of the page. This forces the page heading below downwards.

Groups

Use only one banner per page.

Icon

The close icon uses functional–close–24px.

Behaviour

Banners are persistent unless users navigate away from the page, or dismiss it by selecting the icon.

Content

Title

  • Keep short, clear and to the point.
  • Depending on the situation, you can use a more friendly tone.

Description

  • Include if needed to give more detail.
  • Follow our guidance on clear accessible links.
