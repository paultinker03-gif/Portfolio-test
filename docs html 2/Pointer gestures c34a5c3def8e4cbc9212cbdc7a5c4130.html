Pointer gestures

Pointer gestures play a crucial role in web accessibility, ensuring that users with disabilities can navigate and interact with web content effectively. Here are some key considerations:

Keyboard Accessibility:
Many users rely on keyboards instead of pointing devices, so it's important to ensure that all interactive elements on a website are keyboard accessible. This includes using proper HTML elements like buttons and links, providing keyboard focus indicators, and supporting keyboard navigation.

Touchscreen Accessibility:
For touchscreen devices, such as smartphones and tablets, ensure that touch targets (buttons, links, etc.) are large enough and have adequate spacing to prevent accidental taps. Users with motor impairments may have difficulty with small, closely spaced elements.

Hover and Hover-Dependent Actions:
Avoid relying solely on hover interactions, as they can be challenging for users who can't use a mouse or have difficulty hovering. Instead, provide equivalent interactions that can be triggered by clicks or taps.

Multi-Touch Gestures:
Be cautious with multi-touch gestures as they can be challenging for some users. Offer alternative methods for performing the same actions, such as buttons or gestures with fewer touch points.

Gesture Customisation:
Allow users to customise pointer gestures whenever possible. Some individuals may require specific gestures due to their accessibility needs.

Any actions that are carried out by using a gesture, such as swiping and pinching, should also be possible with a button(s).

We currently have 3 instances within our apps that need to be considered. However we should be mindful of any new components that are created.

Switch

We currently only use the Switch to turn on Face ID or Touch ID. This component doesn’t rely on a gesture, and uses the click/tap action.

Upload

Within File upload a user can drag and drop a choose a file, but this task can also be done by clicking the link ‘choose a file’.

Complex table (Genius) - Settings drawer

A user can rearrange the list by dragging and dropping the items. Currently this is not possible to make changes with just buttons. However, during Q1 2023 we will be adding this functionality.

It is currently possible to change the order using keyboard interactions.
