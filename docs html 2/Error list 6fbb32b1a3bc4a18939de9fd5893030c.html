Error list

Figma linkStorybook link

Error lists are a type of alert specifically for forms. If there are any errors found after the user submitted form details, the error list will appear at the top of the page similar to the Alert component. The body description lists each field error message as clickable links that automatically scroll to the relevant field.

Use when

Validating information in forms.

Don't use when

Validating information not in forms, use Alert instead.

Elements

  1. Icon – Informs users of the alert variant at a glance.
  1. Title – Quick overview of the alert. Usually the most actionable details.
  1. Body text (optional) – Provides additional detail.
  1. Links – Links to next steps when relevant.

Visual

Placement

Always place towards the top of the page, just below thePage heading and Divider.

Size

Always full-width.

Colour

The border, icon and body text links use negative-primary core.

Behaviour

When selecting one of the alert description links, the page will automatically scroll downwards to the relevant form input. This helps users view all form errors in one place and allows them to resolve each quickly.

Content

Title

  • Always "There is a problem" if one error or "There are a few problems" for multiple errors.

Links

  • The link should exactly match the field error message. Follow our guidance on writing error messages.
  • Keep to one short sentence if possible.
  • Clearly describe the action they need to take, instead of listing what was wrong.
  • If relevant, start with active verbs such as "Select" or "Enter".
