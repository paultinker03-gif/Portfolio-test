Page heading

Figma linkStorybook link

The page heading designates the top of each page. It contains a title and may include a back link or lede.

The page heading orientates users by providing the most important information straight away. It provides a consistent page structure throughout the entire experience.

Use when

Clarifying the immediate context of a page.

Don't use when

Designing dashboards or confirmation pages.

Elements

  1. Title – Summarises the primary page content as succinctly as possible.
  1. Text link (optional) – Should be a link to the previous page.
  1. Lede (optional) – Short descriptive text under the title to provide additional information or context about the page.

Visual

Placement

Place the page heading at the top of the page.

If using a Progress indicator, place it above the page heading.

Groups

Use one page heading per page.

Typography

See more details on Typography.

Colour

Use the base–2 palette by default.

On a start page template, such as in Finhabits, you can use the base–3 palette. This will help differentiate this page from the rest of the platform when it has no clear dashboard or home.

The Divider below is optional if the background colour is fairly contrasted.

See more details on Colours.

Behaviour

Users can select the text link to go back to the previous page.

Content

Title

  • Keep headings scannable.
  • For action headings, use the same verb in the action button.

Lede

  • Only use a lede when context is needed for users to complete their task, set expectations or reduce liability.
  • Keep ledes short. Consider using the body copy if text goes over one sentence (or two lines on a desktop screen).

Text link

  • Match the title and styling of the previous page exactly.
  • Include all the text as part of the link.

Pattern

Title

Context title

PurposeClarifies context for the user
Pattern<Page name>
Example• All contributions
• Security options
• Opt in requests

Action title

PurposeClarifies action that user needs to take
Pattern1. <Verb the noun>
2. <Verb your noun>
Example1. Add Direct Debit mandate, Edit personal details, Replace signatory
2. Uploading your file

Lede

PurposeGive more context for the user to complete their task, set expectations or reduce liability
Pattern1. <To do X, verb the noun.>
2. <Verbing the noun helps you do X>
3. <If X happens, you'll see Y>
Example1. To submit contributions, upload a CSV or XLS file
2. Download a template file to complete before you add your clients
3. If clients notify you of new leavers, you'll see a notification on this page
