Why we use patterns

We have a broad idea of how we do content design at Smart but there are some shared patterns that can help us improve the consistency across all of our platforms and products. Excellent content makes a difference to the user experience.

We can pre-populate our drag-and-drop Figma components to reflect our content patterns and our voice, tone and style. This sets our designers up for success and creates quality content right from the start, reducing the need for checks and feedback.

When we use patterns

It’s not always appropriate to use content patterns. When thinking about the double diamond of design, we use content patterns when converging not diverging.

Do use forDon’t use for
• Auditing content
• Iterating content
• Growing the design system		• Research phases
• Ideation phases

Actions

Buttons

PurposeLet the user navigate or take action.
Pattern• “Verb the noun”
• “Verb your noun”
• “Verb”
• “Verb now”
NotesWhere there is an action heading, use the same verb that’s been used in the heading.
Some standard terms we use on our buttons:
• “Continue” (not next)
• “Back”
• “Cancel“
• “Edit” (not modify)

UntitledNotesUse a group of nouns that are designed so they work well together.
Avoiding prepending “your” to menu items. For example use “Account” and not “Your account”.

Ledes and descriptions

PurposeGive more context for the user to complete their task, set expectations or reduce liability.A lede is a short strip of text that appears immediately below a heading and before any body copy.Files
PatternTo do X, verb the noun. Verbing the noun helps you do X. If X happens, you’ll see Y
NotesKeep ledes short. If you find yourself going over one sentence (or two lines on a desktop screen), then consider using the body copy instead of a lede.Example of a lede:Remember, only use a lede if it’s absolutely necessary.


Empty state

PurposeSet expectations for the user. Indicate what they need to do. Or build excitement!
PatternIf user can do something to change the empty state
• “Verb the noun
To verb X, verb the noun.
[Button: Verb]”
• Once you’ve verbed the noun you’ll see X [here]
• “[<area name> or omit]Verb the noun to see X [here]
[Button: Verb the noun]”
If user can’t do anything to change the empty state or has to wait for something
• “[<area name> or omit]
[If/once] X happens, you’ll see Y [here]”
If a field with a dropdown selection:
• “Select option”
NotesFor example:
• “Once you’ve made your first payment, you’ll see a list of transactions here”
• “If we approve your request, you’ll see it here.”
• “Select an option to a see a list of matching employees.”

Hint text

PurposeHelp the user provide specific formats or informations for fields.Files
Pattern“For example, <correct format>”“Use <description of what to use”
NotesExamples:“For example, 01 October 1990”“Use a mobile number if you have one”“Use the name on your passport”


Controls

PurposeTell people the name and state of possible settings/preferences
Pattern• “Verb noun”
NotesIdeally, copy should remain the same for the control regardless of its state, especially if it’s a switch. The state should be reflected using the UI.
Examples:
• “Mute microphone”
• “Hide payments”
Ensure that the verbs are consistent. For example, don’t mix “show” and “hide” commands.

Text input

PurposeHelp users to enter accurate information
Pattern• <Common information name>
• Verb the noun (confirm email)
NotesExamples:
• “Email address”
• “First name”
• “Phone number”
• “Confirm your email address”
• “Enter your message”

Transition / loading

TitlePurposeLet the user know an action is taking placeFiles
UntitledPattern• “We’re verbing the noun”
• “Verbing your noun”
Where the space is very small, use an ellipses
• “Verbing…”
UntitledNotesAlways use text to inform the user something is happening, even if there is no further information.
Spinners require context.


Confirmation

TitlePurposeLet the user know an action has successfully taken place / finished.Files
UntitledPattern• “We’ve verbed your noun”
• “You’ve successfully verbed your noun”
If the space is very small and you have used the ellipses variant for transition, use:
• “Noun verbed”
UntitledNotesWhere possible, if you are saving, uploading or downloading something, say where the item has been saved/uploaded/downloaded to.
For example, “We’ve saved your file to your documents folder.”
Where possible specify a record that the action has been completed for.
For example, “We’ve updated the details for Miss Jane Doe”.

Detour

TitlePurposeInforming the user that they need to complete a different task before they can complete the task they’re currently attempting.Files
UntitledPattern• “Verb the noun [or omit]
<Describe the problem>. To verb X you need to verb Y.
[Button: Verb]”
• “You need to do Y before you can X”
UntitledNotesFor example:
• “Remove an admin
You already have two admins. To make this user an admin, you first need to remove an existing admin.
View admins”
• “You already have two admins. To make this user an admin, you first need to remove an existing admin.”

Blocking - solution known.

TitlePurposeInforming the user they can’t do something until it is unblocked by someone or something else.Files
UntitledPattern• “You can’t verb X until Y happens.”
• “You can’t verb x right now
<description what the roblem is>”
UntitledNotesFor example:
• “You can’t contribute to this scheme until your employer enrols you.”

Blocking - solution not known.

PurposeInforming the user they can’t do something as they are blocked by something or someone else.
Pattern• “Sorry, you can’t verb the noun right now.”
• “Sorry, we couldn’t verb the noun.”
NotesFor example:
• “Sorry, we couldn’t update the details for Miss Kim Fox”
• “Sorry, you can’t update your phone number right now.”
