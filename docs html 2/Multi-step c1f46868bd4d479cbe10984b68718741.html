Multi-step

The multi-step pattern presents an end to end journey in a series of specific steps. By dividing a task into smaller sub-tasks, we help users keep on track to complete it.

It uses the Progress indicator to display how many steps there are in a user journey, versus how many are left to complete.

When using multi-step there must be a minimum of 2 active steps where the user is required to provide or review information.

A review page is also considered to be an active page. Review pages are optional.

Non-active pages include tutorial, confirmation and edit (hub and spoke model).

At the end of the multiple journey we show a Confirmation page. There are two variants of a confirmation, depending on the required action success or Error.

Hub and spoke model

A Hub and Spoke model is a pattern that consists of a central hub from which all activities begin. It is used when several independent tasks are happening at the same time or when screen real estate is limited.

Review page

The review page uses the hub and spoke model. This is the last step before we show a confirmation page and is optional. It gives the user an opportunity to amend information they have provided at each step.

It follows a hub and spoke model. When the user returns to a step the following differences will be present:

  • Remove progress indicator - because the sequence is no longer true in this hub and spoke flow.
  • Only a save button that will save all changes and take them back to the review page.
  • Cancel will just cancel this and return to the review page without saving the changes
  • Remove quit functionality
