Radio

Radio buttons are an input control that collects information. Users can only select one option from multiple radios in a list. When a user selects one radio, a previous choice is automatically unselected.

Radio buttons use our Form control - basic structure as a base.

Use when

Selecting one option from a list of related items.

Don't use when

Users can select more than one option, use Checkbox instead.

Elements

  1. Group label – Describes the group of options or provides guidance for making a selection.
  1. Hint text (optional) – Description giving additional context if needed.
  1. Unselected radio – Default input state.
  1. Selected radio – Shown after selection.
  1. Checkbox label – Describes the information you can select or unselect.
  1. Checkbox hint text (optional) – More context if needed.

Visual

Alignment

Align the group label to the right of the radio button.

Vertically stack the radio buttons to make them easier to scan.

Groups

If the list of items is too long, consider:

  • separating one list into multiple lists with headings
  • using Select instead

Behaviour

States

Radio buttons can be either of two states:

UnselectedThe default view of a radio button.
SelectedWhen users select a new radio button, a previous choice is automatically deselected.

Content

Key elements

Group label

  • Use to describe the broad category of radio buttons or what actions users can take.

Hint text (optional)

  • See our guidelines on hint text in Form control - basic structure.

Checkbox label

  • Always use clear and concise labels when possible.
  • End with a full stop if the label includes more than one sentence.
  • Labels appear to the right of radio inputs.
  • Avoid using links in the label.
  • List options in a logical order. For example, most likely to least likely to be selected.
  • Avoid ordering alphabetically because this doesn't localise to other languages.
  • Make sure labels don't overlap. For example, low, low/medium, high.

Checkbox hint text (optional)

  • Include links relevant to a specific radio button in the hint text needed.
