Search

Figma linkStorybook link

Search allows users to quickly find content by specifying key terms or keywords. This helps reduce any large list of possible results. Search is a customised version of Text Input, with added functionality.

The search component uses our Form control - basic structure as a base.

Use when

Searching for specific content from a large list of possible results.

Elements

Image of "anatomy" with numbered list with standardised terms and functions.

  1. Label – Description of searchable content.
  1. Close icon – Quick option to clear text.
  1. Search button – Search trigger.

Guidelines

Displaying results

It's important to clearly indicate which results are being matched. We highlight the result that's closest to the entered term to make this clear.

Cancel search

When users want to remove their data, selecting the "x" close icon will clear the field. This behaves similarly to Combo (to do).

Content

  • All search fields must have a label.
  • Include enough detail in the results for users to quickly assess if it's relevant to them.
