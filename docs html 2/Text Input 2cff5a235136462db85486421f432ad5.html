Text Input

Figma linkStorybook link

Text input allows users to input short-form content and data. We accept both letters and numbers in multiple formats depending on the context.

For guidance on data only inputs see Number input.

Use when

Entering a single line of text.

Don't use when

Entering long-form content over one sentence, use Text area instead.

Elements

  1. Label
  1. Hint text (optional)
  1. Field
  1. Add on (optional)
  1. Button (optional)
  1. Selector (optional)

Guidelines

  • Where possible, help reduce errors by enabling input masking. For example, adding spaces or hyphens between characters.
  • No maximum character limit unless there is a clear defined character limit, such as identification numbers.

Modifiers

Add-ons

Add-ons provide more information about the specific formatting we need from users. They're static elements that can't be interacted with. For example, percentage symbols or currency format.

Add-ons can be placed to the left or right of the text input field.

Buttons

Buttons provide more options to enter and edit input. For example, increase or decrease buttons for numerical text. Buttons can be combined with add-ons on the same text input.

Combos

The combo combines the functionality of text input and Select components. There are two ways to interact with the combo:

  • select an option from the select to input text in the field automatically
  • begin entering text into the field which will populate if it finds an exact match

Always position the select on the left.

States

The text input has a non-edit state. This is to be used within a form edit page where information exists but cannot be edited by a user.

An example of this is the Company URL input within the Employer page - Edit company details.

Content

Label

  • Every text input must have a label.
  • Keep labels short and descriptive (ideally, one or two words).
  • Always use sentence case.
  • Add "(optional)" to the end of the label text if the field is optional.

Hint text

Use hint text to give more information on what to input or how to input it.

See our guidance on writing hint text in Form control - basic structure.
