Page title

Page titles are an essential element of web accessibility as they provide users with crucial information about the content and purpose of the page. This is also know as a Browser title or Tab title.

Here are some guidelines to ensure accessibility on page titles:

HTML Title Tag:
Use the HTML <title> tag to define the page title. This is the element that appears in the browser's title bar and is usually displayed as the clickable link in search engine results.

Descriptive Titles:
Page titles should accurately and concisely describe the content of the page. This helps users understand what the page is about before they open it. Avoid generic titles like "Untitled" or "Home Page" as they don't provide meaningful information.

Contextual Relevance:Ensure that the page title accurately reflects the content of the page. Misleading titles can confuse users and may lead to frustration. The page titles should match the heading (Content heading or Action heading), with “ - Smart Pension” appending it, e.g. “Investments - Smart Pension”. With that said, this is dynamic and not hard coded so can be changed to anything

Unique Titles:
Each page within a website should have a unique title. This allows users to distinguish between different pages when navigating with multiple tabs or bookmarks. It should:

  • clarify the context for the user.
  • clarify the action the user needs to take.
  • clarify the step the user is on in a multi step.

When the page title will change:

  1. If URL is changed then the page title should be changed.
  1. If URL is not changed but the content changes significantly then we also should update the page title, e.g. Investments flow. This is a multistep flow but due to back-end limitations we can’t serve different URLs.
  1. However, if we open a drawer/modal the page title SHOULD NOT be changed

Title Length:
Keep page titles reasonably short, typically between 50 to 60 characters. This ensures that the title is fully visible in search engine results and on browser tabs.

Avoid All Caps:
Writing page titles in all capital letters can be difficult to read and understand, especially for people with cognitive difficulties. Stick to sentence case or title case instead.

Language Clarity:
Use clear and simple language in page titles. Avoid abbreviations, jargon and acronyms that might not be familiar to all users.

Dynamic Content:
As default our React app is a single-page application and we should ensure that the title is updated when the content changes. This helps users stay oriented as they interact with the page.

By following these guidelines, we can create more accessible page titles that enhance the user experience for all visitors, regardless of their abilities.
