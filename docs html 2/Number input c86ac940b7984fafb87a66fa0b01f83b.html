Number input

Number inputs allow users to input short-form data.

  • Number inputs don’t support letters or special characters. The only exceptions:
    • Some number inputs support decimals.
    • Phone input supports ‘+’.
  • When whole numbers are required use additional hint text to highlight this.
  • If decimals are not allowed, then the backend Form validation will highlight this once the user clicks ‘Save’ or ‘Continue’.

Don't use to

  • Support short-form content and data. Use Text Input instead.

Percentage

If page/client supports decimals

  • then we will allow the user to enter one or two decimals depending on their acceptance rules.
  • when 1 decimal is supported users can use the button and keyboard up and down arrow keys go through whole numbers.
  • when 2 decimals are supported users can use the button and keyboard up and down arrow keys go through 1 decimal numbers.

If the page/client does not support decimals

  • then we will still allow the user to enter one decimal, but this will be picked up by the backend validation.
