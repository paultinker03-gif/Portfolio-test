Form control - basic structure

Figma linkStorybook link

The basic input structure contains the building blocks for all of our form input components. They each contain the same core elements – label, hint text, input field and the error message.

Elements

Most form elements follow the same basic structure:

  1. Label – Describes the input and communicates optionality.
  1. Hint text (optional) – Use if the user might need additional context to input the information correctly.
  1. Field – Where users enter the information.
  1. Error message – A form field error appears below the field if triggered.
  1. Inline alert (optional) – communicate information in a specific section of a page.
  1. Badge (optional) – small visual indicators used to communicate granular detail about other elements.

Content

Label

  • Every form input must have a label.
  • Keep labels short and descriptive (ideally, one or two words).
  • Always use sentence case.
  • Add "(optional)" to the end of the label text if the field is optional.
  • Don’t mark mandatory fields with asterisks.

Hint text

Use hint text to give more information on what to input or how to input it. It can include guidance such as:

  • a specific format to follow
  • what information to enter
  • why we're asking for sensitive information
  • how to interact with the field

Remember that hint text is optional so don't include it if it's not relevant or meaningful. Make sure it's not repeating similar information to the label.

Error message

  • Good error messages let a user know there is an error inline and how to fix it.
  • Match the noun in the error message to the field label.
  • Use common simple verbs, such as "Enter" or "Select".
  • Text links are not allowed within error message.
