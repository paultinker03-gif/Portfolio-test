Fonts

We use two fonts in our products - a header font and a text font for everything else.

The default line weight is regular but bold can indicate actions/buttons in instructional content. For example, “press Continue”. You can also use bold sparingly to emphasise important information.

Headings

A heading shows the title or core topics on the page. We use five heading levels which divide sections of information and create a visual hierarchy. Write all headings in sentence case (not Title Case) and without a full stop at the end.

Every page must have a consecutive heading order <h1> to <h5>. For example, <h2> should not be followed by <H4>.

Skipping this order can be confusing and should be avoided.

Text links

Links use the colour Layout-Content-Link and are underlined by default. If your link is at the end of a sentence or paragraph, make sure that the linked text doesn’t include a full stop.
